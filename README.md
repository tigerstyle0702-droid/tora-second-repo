# tora-second-repo
練習用レポジトリです
# 概要
ソースコードPythonで色々な作業を行うレポジトリ
# 環境構築手順
開発マシンにCloneし、VSCodeと連動させる
# 使い方
Git、GitHubの色々な操作を行う
# 学習履歴
- リポジトリを作成してCloneを実施
- 変更内容をCommit
- コミットメッセージをAIで作成
- ブランチを切ってCommit実行
# 自動駆動
- まずログイン画面をレスポンシブルデザインで作成
- 次にPRを作成する

## Login機能
Flaskを使用したログイン画面とパスワード変更画面を実装。

### 実行方法
1. 依存関係をインストール: `pip install -r requirements.txt`
2. アプリケーションを実行: `python app.py`
3. ブラウザで `http://127.0.0.1:5000/` にアクセス

### 機能
- ログイン画面: ユーザー名とパスワードの入力、バリデーション、パスワード有効期限警告
- パスワード変更画面: 現パスワード、新パスワード、確認用入力、バリデーション
